# HoloQA — Silver Gothic Editorial

The current 3D purple wordmark, transparent H/Q monogram, and glowing app tile
are supplied in `new-logo/`. The desktop and site use the approved palette below.

## Palette

- Primary indigo: `#1A12C8`.
- App background: `#0E0E12`.
- Primary silver: `#E4E4E7`.
- Muted silver: `#B9BAC2`.
- Light surface: `#F7F7F9`.
- Raised surface: `#18181E`.
- Violet accents: `#7C76FF` and `#8F89FF`.
- Text: cool silver and slate, with existing contrast-safe result colors kept
  distinct for pass, warning, and failure states.

## Typography and use

- The app keeps its readable Inter / Segoe UI interface typography.
- The website uses an editorial serif stack for its large headlines and silver
  typography, with indigo and violet accents for interactive states.
- Use `HoloQA_Horizontal_Wordmark.png` for horizontal branding,
  `HoloQA_Symbol_Transparent.png` for the standalone mark, and
  `HoloQA_App_Icon_Transparent.png` for app and browser icons. All three have
  transparent backgrounds. The SVG entry points embed the same raster masters.
- The supplied violet artwork is hue-shifted toward cobalt, while preserving
  the silver lettering, alpha channel, and the approved interface palette.
- Desktop chrome, the GitHub Pages site, README, favicon, and Windows icon use
  the updated mark.

The supplied Silver Editorial character is an AI-generated original design.
The website uses the transparent point pose as decorative brand artwork; source
art is retained under `brand/characters/Silver-Editorial/`.
